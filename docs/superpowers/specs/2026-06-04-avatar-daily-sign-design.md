# Avatar Daily Sign UI Refresh Design

## Goal
把现有“功能面板式”界面重做为白底日签感体验：轻占卜、轻解读、轻结果，不再展示开发视角的系统说明。

## Product Direction
- 白底、暖色、留白
- 像内容产品，不像 AI 工具页
- 一屏一个主目标：上传 / 选玩法 / 看结果
- 用户文案优先，弱化系统术语

## Page Decisions
### Home
- 只保留一句主标题、一句说明、一个上传入口
- 删除功能说明卡、流程卡、系统解释区

### Recommend
- 顶部只展示一段头像小结
- 中部主打推荐玩法
- 底部弱化全部玩法
- 删除规则说明、辅助说明区块和复杂侧栏

### Result
- 单次结果成为主视觉
- 评分改成轻量反馈
- 保留返回玩法页，但弱化系统状态感

## Visual Rules
- 主色：暖白、浅金、淡粉、深灰
- 标题：衬线气质
- 组件：更薄边框、更少层级、更少同级信息
- 交互：按钮简洁，避免控制台感
